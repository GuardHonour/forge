FORGE isn't loading — fix it in 2 minutes

Your phone is opening an old, cached version of the app. These steps make it load the fresh build. They take about 2 minutes and you only need to do them once. Safe Your data is kept

1Close FORGE completely

Swipe the FORGE tab away so it's fully closed (not just in the background).

A half-open app keeps serving the old version — it needs to fully restart.

2Reopen the link fresh

Open this link in your browser (Chrome or Safari):

https://guardhonour.github.io/forge/
Open FORGE now

Let it sit on the loading screen 10–15 seconds — it downloads the new build on first open.

3Still stuck? Force-reload the page

  1. Android (Chrome): tap the ⋮ menu (top-right) → tap Reload. Or pull down hard from the top to refresh.
  2. iPhone (Safari): tap the reload ↻ icon in the address bar. If the tab is slow, close it fully and reopen.
A force-reload tells the browser to throw away the stale cached app and fetch the fresh one.

4Still stuck? Clear the site's stored data

  1. Android / Chrome: tap ⋮ → ⓘ (Site info) → Cookies and site data / Clear & reset → confirm → reopen the link above.
  2. iPhone / Safari: Settings → Safari → Advanced → Website Data → find github.io → delete it → reopen the link.
This is the sure-fire fix. It wipes the old cached app entirely so FORGE installs brand-new.

5Re-add FORGE to your home screen

  1. Android / Chrome: when FORGE loads, tap ⋮ → Add to Home screen.
  2. iPhone / Safari: tap Share → Add to Home Screen.
If you had the old app icon installed, delete it and re-add — this guarantees the updated app.

Still not working?

Check your internet is on, and try a different browser (e.g. open in Chrome if you were on Safari).

If FORGE loads in the browser but not the installed app — delete the home-screen icon and re-add it (step 5). That fixes it 99% of the time.

RECOVERY TIP: your training logs live in the app's own storage on this phone and are not touched by any of these steps. Clearing the cache does not delete your data. If you ever want a backup, use the app's export button before doing anything.
