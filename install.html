FORGE

Training Log · install it like an app

Open the app →

Android (Chrome)

  1. Tap Open the app above
  2. Tap the ⋮ menu (top right)
  3. Tap Add to Home screen / Install app
  4. Confirm — FORGE appears with the anvil icon

iPhone / iPad (Safari)

  1. Tap Open the app above
  2. Tap the Share button (square with arrow)
  3. Scroll and tap Add to Home Screen
  4. Tap Add

Desktop (Chrome / Edge)

  1. Open the app
  2. Click the install icon in the address bar (or menu → Install FORGE)

Your training data is stored only on your device — nothing is uploaded, no account needed. Install once and it works offline.
